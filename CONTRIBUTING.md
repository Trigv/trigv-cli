# Contributing

## Development

```bash
npm install
npm test
npm run lint
npm run build
```

## Pull requests

1. Fork `Trigv/trigv-cli` and branch from `main`
2. Run tests, lint, and build
3. Update `CHANGELOG.md` for user-visible changes

## API contract

Match [Trigv OpenAPI](https://api.trigv.com/openapi.yaml).

## Security

Never commit API keys. Do not log credentials in error output.
